# ABK Clinic — демо-концепт сайта

Сайт-предложение для медицинского центра ABK Clinic (Астана, Мангилик Ел, 36).
Это **демо**: на каждой странице есть плашка «не официальный сайт», страница закрыта от поисковиков.

## Как открыть

Распакуйте архив и откройте `index.html` двойным щелчком: сайт работает прямо с диска, вместе со шрифтами.

Если нужно проверить так, как будет на хостинге, запустите в папке сайта локальный сервер:

```
python -m http.server 8000
```

и откройте http://localhost:8000. Язык меняется переключателем в шапке или параметром `?lang=ru`, `?lang=kk`, `?lang=en`.

Мобильную версию удобно смотреть в Chrome: F12 → значок телефона → iPhone или Android.

## Как устроена мобильная версия

- **Меню** — компактная карточка под кнопкой ☰, страница остаётся видна.
- **Кнопка WhatsApp** — бирюзовый кружок справа. На первом экране у неё есть подпись «WhatsApp», дальше она становится кружком в нижней панели.
- **Нижняя панель** «Позвонить / Записаться» появляется, когда первый экран пролистан.
- **Запись** — шторка снизу. Её открывают все кнопки «Записаться», карточки направлений, строки прайса и программы чек-апа; услуга подставляется сама. Шторку можно закрыть крестиком, смахнуть вниз или нажать на затемнение.
- **Длинные списки листаются в сторону**: 16 направлений (три ряда), этапы гастроцентра, программы чек-апа, команда клиники. Под каждой лентой — полоска прогресса и стрелки.
- **Прайс** — вкладки «Диагностика / Врачи / Процедуры», разделы переключаются нажатием или свайпом. В длинном разделе сначала 6 строк и кнопка «Показать ещё». При поиске показывается обычный список.
- **Подбор чек-апа** — «Для кого» — четыре кнопки, «Что важнее проверить?» — девять плиток с иконками; подходящие программы встают в начало ленты.
- **Маршрут в 2ГИС** — кнопка под адресом на первом экране и в контактах.

На компьютере (ширина от 960px) всё остаётся сеткой: форма записи стоит рядом с первым экраном, прайс — одним списком.

## Логотип и врачи

**Логотип.** Положите файл в `assets/img/` (например, `logo.png` с прозрачным фоном или `logo.svg`)
и впишите путь в `assets/js/i18n.js` → `config.logo`. Логотип появится в шапке, в подвале и на вкладке браузера.
Если на логотипе уже написано «ABK Clinic», поставьте `config.logoWithName: true` — название не будет дублироваться.
На узком телефоне в шапке остаётся только логотип.

**Врачи** (блок «Кто о вас позаботится»). Данные — в `i18n.js` → `team`. Пока там специальности клиники.
Для врача впишите `name` (имя), `photo` (путь к фото в `assets/img/team/`) и `exp` (стаж) — карточка станет карточкой врача,
а подпись «Здесь появятся фото…» исчезнет сама. Кнопка «Записаться» подставит услугу из поля `service`.

## Что где лежит

| Файл | Что внутри |
|---|---|
| `index.html` | Разметка страницы и иконки |
| `assets/js/i18n.js` | **Все тексты на 3 языках, цены, услуги, чек-апы, телефон** — правьте только здесь |
| `assets/js/app.js` | Логика: прайс с вкладками и поиском, подбор чек-апа, шторка записи, листалки, цели аналитики |
| `assets/css/site.css` | Стили: мобильная версия по умолчанию, версия для компьютера с 960px |
| `assets/css/fonts.css` | Подключение шрифтов файлами — для хостинга |
| `assets/css/fonts-embedded.css` | Те же шрифты, встроенные в CSS, — подключается сам, когда `index.html` открыт с диска |
| `assets/fonts/` | Шрифты Onest и Lora (с казахскими буквами), лежат на сайте — без Google Fonts |
| `assets/img/` | Логотип и фото клиники (сейчас пусто — инструкция внутри) |

## Запись

Форма не хранит данные. Она собирает услугу, удобный день, имя и телефон и открывает WhatsApp
клиники (+7 776 533 96 26) с готовым сообщением. Номер меняется в `i18n.js` → `config.whatsapp`.

## Кнопка WhatsApp

По правилам бренда WhatsApp его логотип нельзя перекрашивать и вписывать в другие фигуры,
поэтому на кнопке — иконка чата в цветах сайта и подпись «WhatsApp».
Если клиника захочет официальный значок, его берут только из брендовых материалов WhatsApp
(https://www.meta.com/brand/resources/whatsapp/whatsapp-brand/) и ставят без изменения цвета.

## Аналитика (воронка)

Каждая важная кнопка отправляет событие в `window.dataLayer` (для Google Tag Manager)
и в Яндекс Метрику, если указан номер счётчика в `i18n.js` → `config.metrikaId`
(код счётчика Метрики вставьте в `<head>`).

| Событие | Когда срабатывает |
|---|---|
| `click_whatsapp`, `click_phone` | Нажали WhatsApp или телефон |
| `booking_open` | Открыли шторку записи на телефоне |
| `open_direction` | Нажали на карточку направления |
| `price_book`, `checkup_book` | Нажали «Записаться» в прайсе или у программы |
| `price_tab`, `price_kids` | Переключили раздел прайса / фильтр «Детям» |
| `quiz_complete` | Ответили на оба вопроса подбора чек-апа |
| `booking_error`, `booking_submit` | Ошибка в форме / заявка отправлена в WhatsApp |
| `cta_hero`, `cta_bar`, `cta_menu`, `cta_header`, `cta_contacts`, `cta_gastro` | Какая кнопка «Записаться» сработала |
| `scroll_50`, `scroll_90` | Долистали страницу до половины / почти до конца |
| `lang_switch` | Сменили язык |

## Перед запуском на домене клиники

1. Удалить демо-плашку (`.demo-ribbon` в `index.html`), строку `<meta name="robots" content="noindex, nofollow">` и заменить `robots.txt`.
2. Вставить логотип клиники и настоящие фото клиники и врачей.
3. Сверить с клиникой цены, часы работы, услуги для детей и тексты на казахском и английском.
4. Добавить номер лицензии и полную политику конфиденциальности.
